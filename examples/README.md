# Example Configuration

`starter-plan.example.json` is a neutral demonstration plan.

It is not a recommended curriculum.

It exists only to show the Community Edition configuration format.

The example uses:

- two weeks;
- short daily work blocks;
- three demonstration skills;
- one small project;
- one public-domain reading example;
- one generic sketching practice track.

Copy the file into `user-config/` before you customize it.

Do not edit the public example with personal data.
