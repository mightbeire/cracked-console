# Example Configuration

The examples are neutral demonstrations of Community Edition configuration formats.

They are not recommended curricula.

## Starter Plan

`starter-plan.example.json` demonstrates the ordinary schema-v1 plan format.

It uses:

- two weeks;
- short daily work blocks;
- three demonstration skills;
- one small project;
- one public-domain reading example;
- one generic sketching practice track.

## Weekly Driver

`weekly-driver.example.json` demonstrates the optional week-level mastery convention without using a private curriculum.

It shows:

- reserved non-required `WEEK_*` contract blocks;
- ordinary daily execution underneath the weekly contract;
- one `WEEK_MASTERY_PROOF` scheduling anchor;
- week-linked verified evidence as part of mastery;
- a rest day that contains only non-required contract metadata and no required learning work.

Both examples are validated by the repository release checks.

Copy the appropriate example into `user-config/` before you customize it.

Do not edit public examples with personal data.
