# Privacy

Cracked Console is designed for local use.

## Core Data Flow

Core use stores plan and execution data on the local computer.

Cracked Console does not require an account, hosted database, cloud synchronization, API key, or mandatory AI service.

## Repository Data

The public repository must not contain a maintainer's personal learning plan or local execution records.

The repository ignores personal plan files, SQLite databases, backup files, environment files, and generated build output.

## User Responsibility

A local-first design does not make local files invisible to the operating system.

Protect the Windows account and device.

Store backups in a location that matches your own security needs.

## Optional Integrations

A future optional integration can have its own privacy implications.

Document those implications before the integration becomes part of a public release.
