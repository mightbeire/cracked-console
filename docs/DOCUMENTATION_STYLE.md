# Documentation Style

All original Markdown documentation in this repository must use these standards.

## Primary Language Standard

Use ASD-STE100 Simplified Technical English.

- Use short, direct sentences.
- Prefer the active voice.
- Put one main instruction or idea in each sentence.
- Use the same term for the same thing.
- Avoid unnecessary synonyms.
- Define technical terms before you depend on them.
- Avoid idioms, slang, and decorative wording.
- Make instructions explicit.
- State conditions before actions when the condition matters.

Technical accuracy takes priority over forced simplification.

## Editorial Standard

Use the Chicago Manual of Style for grammar, punctuation, capitalization, headings, numbers, and editorial consistency.

## Code and Commands

Do not rewrite code, commands, file names, identifiers, or required technical strings to match prose style.

Use fenced code blocks for commands that a user can copy.

## Legal Text

Do not rewrite standard legal text, licenses, third-party notices, or required attribution text into Simplified Technical English.

Preserve the official wording.
