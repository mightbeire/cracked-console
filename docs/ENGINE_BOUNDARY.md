# Reusable Engine Boundary

The engine stores plans and execution records.

The engine does not define what a person must learn.

## Plan Data

Plan data can define weeks, days, work blocks, resources, skills, projects, reading, and practical work.

The user owns this data.

## Execution Data

Execution data records what happened. It can include completed blocks, timer state, learning logs, assessment attempts, repair tasks, evidence, project progress, skill-level assignments, reading reports, and practice logs.

## Separation Rule

The public repository must not contain the maintainer's private plan as an application default.

Example configuration must use neutral demonstration content.
